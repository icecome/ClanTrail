- 关键前置：Gradle 直连国内镜像（`~/.gradle/init.gradle` 阿里云）、`CARGO_INCREMENTAL=0` 规避 rustc ICE、构建用 Bash 工具 `run_in_background` 托管（不可在命令内 `nohup &`，会话结束会被回收）。

### 注意事项（重要）
- `gen/android/` 是 `tauri android init` 自动生成的，`BuildTask.kt` 的改动会在下次 `tauri android init` 被覆盖。若重 init，需重新应用上述一处字符串替换。
- debug APK 体积大（unoptimized+debuginfo）；要瘦身用 release 构建（去掉 `--debug`）。
